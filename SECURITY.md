# Security and privacy

Found a way the tracker could leak something about you, let someone else into the dashboard, or run something it shouldn't? Please tell me privately first, not in a public issue.

## How to report it

- **On GitHub:** open the repo's **Security** tab and choose **Report a vulnerability**. Only I can see it.
- **On Discord:** send a direct message to Aurelius_Draco (join through https://discord.gg/8kH5pfHYbe).

Say what you found, how to make it happen, and which version you're on. Crop the in-game QR code and other players' handles out of any screenshots.

## Which versions get fixes

Only the latest release.
